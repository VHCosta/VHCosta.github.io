Runner

Runner is a side-scrolling endless runner game built using the SimpleGraphics library.
Developed as our first group project at Academia de Código’s bootcamp over one week, it challenges players to jump over obstacles and maintain momentum.
Check out the repository to learn more and try it out.

ASCII BattleShip AKA BattoruShippo

ASCII Battleship (BattoruShippo), is a text-based Battleship game designed for terminal play.
Leveraging multithreading and TCP sockets, this project was completed as our second group project at Academia de Código over a weekend, showcasing early teamwork and network programming skills.
Visit the GitHub repo for details.

Map Editor

Map Editor is a graphical tool built with SimpleGraphics that lets users draw by painting squares on a grid, complete with save and load functionality.
This project, developed during a class at Academia de Código, emphasizes fundamental design and file-handling techniques in a simple yet effective interface.
Visit the GitHub repo for details.

Concurrent Chat

Concurrent Chat is an IRC-like chat application that supports multiple users connecting via NetCat or Nmap’s ncat.
Created as part of a concurrent programming class at Academia de Código, it highlights real-time communication and multithreading.
It stands out as one of our most fun projects to build—explore the GitHub repo to see how you can set it up yourself!

(i) Will Survive

(i) Will Survive is an interactive narrative game where the character “i”—named for its resemblance to the letter— battles its greatest enemy—Fear—through an epic game of Rock-Paper-Scissors.
Developed during a 24-hour Hackathon at Academia de Código, the project features a comic book aesthetic and dynamic animations powered by the ScrollMagic JavaScript library.
Experience the live site to immerse yourself in the story.



Pokémon Availability Checker

Pokémon Availability Checker is a two-part application that verifies the availability of Pokémon across various games using a bundled static dataset for efficiency.
Developed entirely from scratch over one week in January 2025, this project is still evolving with continuous refinements and additional data, and features a ReactJS-based frontend and an Express-powered backend.
The app is hosted on Netlify (client) and Render (server)—note that the free-tier on Render may experience occasional spin-down delays on first use.
Check out the live demo or the GitHub repositories to explore further.
