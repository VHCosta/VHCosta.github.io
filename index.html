Runner

A side-scroller / endless runner type game made using the SimpleGraphics library.
This was our first group project at Academia de Código's bootcamp, done over the course of one week.
Check out the repo to find out how you can try it!

ASCII BattleShip AKA BattoruShippo

ASCII BattleShip, or BattoruShippo, is a text-based Battleship game which runs on a terminal.
The game is multithreaded so it accepts multiplayer matches through TCP sockets.
This was our second group project at Academia de Código, done over the course of a weekend.

Map Editor

A graphical editor with a moving cursor, made with SimpleGraphics.
You can paint squares on a grid to draw something. It features saving and loading from a file.
This was also done at Academia de Código during class.

Concurrent Chat

An IRC-like chat that multiple people can use.
You can use with NetCat (nc) or Nmap's implementation (ncat).
This was done as part of a class at Academia de Código on concurrent programming.
One of our most fun activities!

(i) Will Survive

A game that tells the story of i (named after looking like the letter ‘i’), who is going against his biggest enemy, Fear itself, in an Epic Battle of Rock-Paper-Scissors.
Part of our Hackathon, our final challenge at the Academia de Código, where we had to develop an app/game/service in 24 hours.
Our group was given the song "I Will Survive" by Gloria Gaynor, and we created a website to tell a story. We gave it a comic book-like feel, and added some animations using a JS library called ScrollMagic.
You can actually see the website live below!



Pokémon Availability Checker

A two part app, with client and server, for checking availability of Pokémon given a selection of Pokémon games.
Written in ReactJS for the frontend and Express for the backend, bundled with a static dataset for efficiency.
This project is being hosted on Netlify (client) and Render (server). Expect some occasional delays in service on the first usages as this free instance of Render does spin down with inactivity.
Currently still missing some data and refining some presentation aspects, but overall, it does its job (for Generations 1-7, excluding Go and Let's Go games, for now -- subject to change)
